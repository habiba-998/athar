# ATHAR: see the attack before it happens

A **public, read-only demo** of ATHAR, a defensive attack-path analysis and decision-validation platform.

- All data is **synthetic**. Nothing here scans, exploits or touches a real system, and no change is ever executed.
- Scores are heuristic indices, **not probabilities**. Evidence labels are declared in the data and not verified.
- Simulations are computed on an isolated copy and are **not stored**; the demo restarts from the sample.
- English and Arabic (RTL), keyboard accessible, phone friendly.

Source code, tests, documentation and the limits of the project: https://github.com/habiba-998/athar
